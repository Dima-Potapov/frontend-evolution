# 01 — Лента постов на чистом JavaScript

## 🎯 Цель этой версии

Понять **базовые механизмы** работы веб-приложения:
- Как HTML, CSS и JavaScript работают вместе
- Как JavaScript управляет содержимым страницы (DOM)
- Как реагировать на действия пользователя (события)
- Как хранить данные в памяти (массив объектов)

## 📁 Структура файлов

```
01-vanilla-js/
├── index.html   — Разметка: структура страницы (что отображается)
├── style.css    — Стили: внешний вид (как выглядит)
├── main.js      — Логика: поведение (как работает)
└── README.md    — Этот файл: описание и заметки
```

## 🚀 Как запустить

1. Открой файл `index.html` в браузере (двойной клик или перетащи в окно браузера)
2. Никакой установки, сервера или командной строки не нужно!

Можно также использовать Live Server (расширение для VS Code) для автоматической перезагрузки при изменениях.

## 📝 Что умеет приложение

- ✅ **Добавить пост** — заполни заголовок и текст, нажми «Опубликовать»
- ❤️ **Лайкнуть пост** — нажми кнопку с сердцем, счётчик увеличится
- 🗑️ **Удалить пост** — нажми «Удалить», подтверди удаление

> ⚠️ Данные хранятся только в памяти. При перезагрузке страницы посты пропадут.
> Простой способ сохранить посты, `localStorage`, — это задание 1 в конце этого файла.
> Настоящее хранение на сервере появится в версии 08 (PostgreSQL).

## 📚 Ключевые концепции, которые здесь изучаются

### HTML
| Концепция | Где используется | Зачем |
|-----------|-----------------|-------|
| `<!DOCTYPE html>` | Первая строка | Указать браузеру версию HTML |
| Семантические теги (`<form>`, `<h1>`) | Вся разметка | Придать смысл структуре |
| Атрибут `id` | Поля и контейнеры | Найти элемент из JavaScript |
| Атрибут `required` | Поля формы | Встроенная валидация без JS |
| `<script src="...">` в конце `<body>` | Подключение JS | Гарантировать, что DOM готов |

### CSS
| Концепция | Где используется | Зачем |
|-----------|-----------------|-------|
| `box-sizing: border-box` | Глобальный сброс | Предсказуемые размеры элементов |
| Flexbox (`display: flex`) | Форма, кнопки | Удобная раскладка элементов |
| Псевдоклассы (`:hover`, `:focus`, `:active`) | Кнопки, поля | Обратная связь при взаимодействии |
| `@keyframes` | Карточка поста | Анимация появления |
| `@media` запросы | Адаптивность | Стили для мобильных экранов |
| Утилитарный класс `.hidden` | Показ/скрытие | Управление видимостью из JS |

### JavaScript
| Концепция | Где используется | Зачем |
|-----------|-----------------|-------|
| `document.getElementById()` | Получение ссылок | Найти элемент по ID |
| `document.createElement()` | Создание карточки | Динамически создать HTML |
| `appendChild()` / `prepend()` | Вставка карточки | Добавить элемент на страницу |
| `element.remove()` | Удаление поста | Убрать элемент со страницы |
| `addEventListener()` | Форма, кнопки | Реагировать на действия |
| `event.preventDefault()` | Отправка формы | Отменить перезагрузку страницы |
| `textContent` (не `innerHTML`) | Вставка текста | Защита от XSS-атак |
| `classList.add/remove` | Стилизация | Переключать CSS-классы |
| `dataset` | Data-атрибуты | Хранить ID в HTML-элементе |
| `Array.push/filter/find` | Работа с массивом | CRUD-операции над данными |
| Стрелочные функции | Обработчики | Краткий синтаксис функций |
| Замыкания (closures) | addEventListener | Функция «помнит» postId |
| Строгое сравнение `===` | Условия | Безопасное сравнение |

## 💡 Задания для самостоятельной работы

1. **Добавь localStorage** — сохраняй массив `posts` в `localStorage`, чтобы данные сохранялись между перезагрузками.
   - Подсказка: `JSON.stringify()` и `JSON.parse()`

2. **Добавь дату** — пусть каждый пост показывает, когда он был создан.
   - Подсказка: `new Date().toLocaleString('ru-RU')`

3. **Добавь редактирование** — кнопка «Редактировать» заменяет текст на поля ввода.
   - Подсказка: `replaceChild()` или изменение `innerHTML`

4. **Добавь поиск** — текстовое поле, фильтрующее посты по заголовку.
   - Подсказка: `String.includes()` и `element.style.display`
